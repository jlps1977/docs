# Documentation Lifecycle Policy

## Statuses

- draft
- review
- approved
- production
- deprecated
- archived

## Lifecycle

1. Draft: document is being created.
2. Review: owner has requested review.
3. Approved: accepted as valid.
4. Production: actively governing system behavior.
5. Deprecated: replaced but retained for history.
6. Archived: historical only.

## Update Rules

Canonical docs require owner approval. ADRs are immutable after approval.
