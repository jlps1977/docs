# ADR Governance Policy

ADRs are immutable architecture decision records.

## Numbering

`LV-[DOMAIN]-ADR-[NUMBER]`

## Required For

- schema changes
- module boundary changes
- AI orchestration changes
- security changes
- monetization architecture changes
- core data model changes

## Immutability

Approved ADRs cannot be edited to change historical meaning. Superseding requires a new ADR.
