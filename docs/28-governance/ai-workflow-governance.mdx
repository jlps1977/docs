# AI Workflow Governance

AI workflows are operational systems and must be documented as such.

## Required Sections

- trigger
- inputs
- outputs
- agents
- prompt chain
- MCP dependencies
- validation layer
- human review points
- retry logic
- failure handling
- cost and latency targets

## Human Review

Human approval is mandatory when workflow outputs affect:

- pricing
- ranking
- ads
- provider status
- customer-facing claims
- legal/compliance wording
