# Prompt Governance Policy

All production prompts must be versioned, owned and linked to workflows.

## Required Metadata

- id
- title
- owner
- version
- status
- model compatibility
- input contract
- output contract
- guardrails
- related workflows

## Change Rules

Prompt changes that alter output shape require MINOR version updates. Prompt changes that break workflow compatibility require MAJOR version updates.
