# Contributing to LUVO DOS

## Branch Naming

`docs/<domain>/<short-description>`

Examples:

- `docs/ads/rtb-decision`
- `docs/ai/provider-classification-workflow`

## Pull Request Requirements

Every PR must include:

- Scope
- Files changed
- Document owner
- Affected modules
- Dependencies
- Changelog impact
- ADR impact
- Prompt impact
- Workflow impact

## Review Rules

- Product docs require Product Owner review.
- Technical docs require Engineering review.
- AI workflow docs require AI Systems review.
- ADRs require Architecture Council review.
