# LUVO Documentation Operating System

Enterprise-grade documentation repository for LUVO, an AI-native local-first modular platform.

## Purpose

This repository is the single source of truth for LUVO product, architecture, AI workflows, governance, prompts, sprints, ADRs, releases, and operational knowledge.

## Operating Rule

No LUVO module may move to production without:

- Product Sheet
- Technical Sheet
- ADR coverage when architecture is affected
- Workflow documentation when AI or operations are involved
- Prompt registry entry when prompts are used
- Changelog entry
- Ownership
- Version
- Dependencies
- Lifecycle status

## Local Mintlify

```bash
npm install
npm run dev
```
